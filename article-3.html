How to Actually Create a Strong Password

6 min read · Guides

Most password advice focuses on complexity rules — one uppercase letter, one number, one symbol — but length matters more than complexity for resisting the kind of automated guessing attacks passwords actually face. A long, random password made only of lowercase letters can be harder to crack than a short, complex-looking one.

Why length wins

Every extra character multiplies the number of possible combinations an attacker has to try. Going from 8 to 16 characters increases the search space so dramatically that it outweighs adding symbol requirements to a short password. If you generate a password, length is the first dial to turn up.

Random beats memorable

A password you can remember is usually a password that follows a pattern — and patterns are exactly what makes guessing easier. A password generated randomly, with no pattern to reverse-engineer, is strictly safer, even if you can't recite it from memory. That's what a password manager is for: it remembers the random one so you don't have to.

The habits that undo a strong password anyway

  • Reusing it. One strong password used on five sites means one breach on any of those five compromises all five.
  • Storing it in plain text. A password saved in an unencrypted notes file is only as safe as whoever can access that file.
  • Skipping two-factor authentication. A strong password helps, but 2FA stops most account takeovers even if the password does leak.
In practice: generate a long, random password for each account, store it in a password manager, and turn on two-factor authentication wherever it's offered. That combination matters more than any single password's complexity.

How long is long enough

There's no single universal number, since it depends on what's being protected and how it's stored on the other end — but as a practical baseline, most current guidance points toward passwords in the neighborhood of 16 characters or more for accounts that matter, generated randomly rather than chosen.
